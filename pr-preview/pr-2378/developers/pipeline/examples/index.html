    Examples¶

    Each example shows a small Haskell program and the intermediate programs of its module Main. Select a tab to see the program in that language.

    The manual build compiles each example with the current compiler. Thus, the output on this page always agrees with the compiler of this version of the manual. If the compiler cannot compile an example, the manual build fails. The compiler made these programs for the target linux-amd64 at the default optimization level.

    The Haskell sources are in the directory docs/aihc-manual/pipeline-examples. To add an example, add a directory with a Main.hs file and a description.md file.

    Type classes¶

    This program uses the classes Num, Enum, Foldable, and Show. In System FC, each class constraint is an explicit dictionary argument, for example $fNumInt. Each type argument is also explicit, for example @tInt.
